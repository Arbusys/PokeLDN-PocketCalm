# Changelog

All notable public-facing Pocket Calm milestones are summarized here. Versions before v1.0.0 were development iterations tested primarily on one T-Dongle S3.

## v1.0.0 — First stable release
- Updated the standalone English-language Windows installer: custom Pocket Calm UI and icon, progress feedback, USB/COM auto-detection with manual fallback.
- Ships the v0.9-derived firmware, with the same protocol and validated display features.
- Prepared a public documentation and support set.

## v0.9 — Efficiency
- Reduced unnecessary idle display and LED update activity; kept core radio/USB behaviour unchanged.

## v0.8 — Themes
- Added five display palettes, the rear-button selector and persisted theme preference.

## v0.7 — Raid lobbies
- Added themed lobby screens based on PokéLDN events already sent by the Windows application.

## v0.6 — Pocket Calm
- Restored legible monochrome trade silhouettes and softened LED behaviour.

## v0.1–v0.5 — Early development
- Added built-in TFT support, trade animations and progressive UI design refinements.
