# PokéLDN Pocket Calm v0.8 — Theme Switch Edition (unofficial)

- Press the **rear BOOT button once while the device is running** to change between five themes:
  Classic, Modern Minimal, Game Boy Color, Crimson Ruby, Ocean Teal.
- Theme selection is saved in NVS and restored after power cycling.
- A brief theme name overlay confirms each selection.
- Keeps v0.7 raid lobbies, v0.6/0.1 monochrome trade sprites, flying Poké Ball,
  and calm cyan/green LED behavior. No desktop application modification needed.
- **Board-specific**: original LILYGO T-Dongle S3, 160 × 80 display.

Validation: desktop rendering tests and code-level checks only; GitHub ESP-IDF build
and hardware validation are still required before public release.
